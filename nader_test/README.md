# دفترچه افراد (People Directory)

یک برنامه‌ی کوچک ASP.NET Core MVC برای **ذخیره، ویرایش و گزارش‌گیری** اطلاعات افراد.

## امکانات

- **ثبت فرد جدید** با نام، نام خانوادگی، کد ملی و شماره تماس
- **ویرایش** و **حذف** افراد (با صفحه‌ی تأیید حذف)
- **مشاهده‌ی جزئیات** هر فرد
- **جستجو** در نام، نام خانوادگی، کد ملی و شماره تماس
- **مرتب‌سازی** بر اساس نام خانوادگی یا تاریخ ثبت
- **صفحه‌بندی** (۱۰ نفر در هر صفحه)
- **گزارش‌ها**:
  - تعداد کل افراد، ثبت‌شده در ۷ روز گذشته، ویرایش‌شده، نام خانوادگی متمایز
  - گزارش تعداد افراد به تفکیک حرف اول نام خانوادگی
  - گزارش ثبت‌نام ۱۴ روز گذشته
  - آخرین افراد ثبت‌شده
  - **خروجی Excel** (xlsx) و **چاپ**
- **اعتبارسنجی کد ملی** با الگوریتم رسمی رقم کنترلی
- جلوگیری از ثبت **کد ملی تکراری** (هم در دیتابیس با ایندکس یکتا و هم در فرم)
- رابط کاربری کاملاً **فارسی و راست‌به‌چپ** با Bootstrap RTL

## پیش‌نیاز

- .NET SDK 8.0 یا بالاتر

## اجرا

```bash
dotnet restore
dotnet run
```

سپس در مرورگر باز کنید: `https://localhost:7xxx` یا آدرس نمایش‌داده‌شده در خروجی.

برای اجرا روی یک پورت مشخص و بدون HTTPS:

```bash
dotnet run --urls "http://127.0.0.1:5188"
```

## دیتابیس

از **SQLite** استفاده می‌شود؛ فایل `people.db` در اولین اجرا به‌صورت خودکار
ساخته و با چند رکورد نمونه پر می‌شود (تنها اگر جدول خالی باشد).
این فایل در `.gitignore` قرار دارد و در مخزن ثبت نمی‌شود.

### ساختار جدول `People`

| ستون | نوع | توضیح |
|---|---|---|
| `Id` | INTEGER | کلید اصلی، خودافزا |
| `FirstName` | TEXT(50) | نام |
| `LastName` | TEXT(50) | نام خانوادگی (ایندکس‌دار) |
| `NationalCode` | TEXT(10) | کد ملی (ایندکس یکتا) |
| `PhoneNumber` | TEXT(11) | شماره تماس، با ۰ شروع می‌شود |
| `CreatedAt` | TEXT | تاریخ ثبت |
| `UpdatedAt` | TEXT | آخرین ویرایش (اختیاری) |

### دستورات مفید EF Core

```bash
dotnet ef migrations add <Name>     # ساخت مایگریشن جدید
dotnet ef database update           # اعمال مایگریشن‌ها
dotnet ef migrations list           # فهرست مایگریشن‌ها
```

## ساختار پروژه

```
Controllers/
  PeopleController.cs      مدیریت افراد: فهرست، جستجو، ثبت، ویرایش، حذف
  ReportsController.cs     گزارش‌ها و خروجی Excel
Models/
  Person.cs                مدل فرد + اعتبارسنجی
  IranianNationalCodeAttribute.cs   اعتبارسنجی رقم کنترلی کد ملی
  AppDbContext.cs          کانتکست EF Core
  PersonListViewModel.cs   مدل صفحه‌ی فهرست (جستجو/صفحه‌بندی)
  ReportViewModel.cs       مدل صفحه‌ی گزارش
Views/
  People/                  Index, Create, Edit, Delete, Details
  Reports/Index.cshtml     صفحه‌ی گزارش‌ها
  Shared/_Layout.cshtml    قالب راست‌به‌چپ فارسی
Migrations/                مایگریشن‌های EF Core
SeedData.cs                داده‌های نمونه
```

## نکته‌ی اعتبارسنجی کد ملی

الگوریتم رسمی: ارقام ۱۰گانه‌ی کد ملی به‌ترتیب در ضرایب ۱۰ تا ۲ ضرب می‌شوند،
مجموع بر ۱۱ تقسیم می‌شود و رقم کنترلی بر اساس باقی‌مانده بررسی می‌گردد.
کدهای با ارقام یکسان (مثل `1111111111`) نیز نامعتبر شمرده می‌شوند.
